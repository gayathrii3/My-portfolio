# Majestic Cinematic Portfolio 🏛️✨

Welcome to the **Majestic Cinematic Portfolio**, a high-fidelity, legendary-themed digital journey designed to showcase technical mastery through a cinematic experience. Inspired by the epic visual language of "Magadheera," this portfolio combines modern web technology with ancient aesthetic depth.

## 🎬 Theme & Inspiration
This portfolio is deeply inspired by the visual grandeur and epic storytelling of the legendary Indian film **"Magadheera"**. The design system, color palette, and interactive elements are meticulously crafted to evoke the feeling of a timeless cinematic journey through a legendary kingdom.

## 🌟 Vision
To transform a traditional portfolio into an immersive saga, where every scroll reveals a new chapter of expertise and every interaction feels like discovering a legendary artifact.

## 🛠️ Technical Arsenal
*   **Core**: HTML5, CSS3, JavaScript (ES6+)
*   **Animations**: [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/) with ScrollTrigger
*   **Styling**: Vanilla CSS with a custom-crafted Design System
*   **Iconography**: [Font Awesome 6 (Premium Visuals)](https://fontawesome.com/)
*   **Typography**: Google Fonts (Cinzel, Montserrat, Inter)

## 🎭 Key Features
*   **Cinematic Entrance**: A portal-based hero reveal with parallax depth.
*   **Legendary Map**: A 2D cinematic map featuring a mouse-tracked "Horse Traveler" navigating through project landmarks.
*   **Interactive Sidebar**: A rich, thematic brown leather-textured navigation with premium golden icons.
*   **Grand Finale**: A majestic reveal of the Udaygadh Fort at the end of the journey.
*   **Cinematic Union**: Reaching "Hands of Connection" that meet in the center to frame social links.

## 🗺️ Project Journey
*   **FURRR**: A high-end Petcare AI application.
*   **Venue Booking**: A professional Android application for venue management.

## 🚀 Getting Started
1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/gayathrii3/portfolio.git
    ```
2.  **Open in Browser**: Simply open `index.html` in any modern web browser to experience the journey.
3.  **Local Development**: Recommended to use a Live Server (like the VS Code extension) to ensure smooth asset loading and GSAP performance.
